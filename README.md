# 🏴‍☠️ Python海賊王への道 - 学習アプリ

ワンピース風のUIデザインで、楽しくPythonを学べるWebアプリケーションです！

## 🌟 特徴

- **ワンピース風デザイン**: 海賊をテーマにした冒険的なUI
- **レスポンシブ対応**: スマホ、タブレット、PCで快適に学習
- **進捗管理**: LocalStorageで学習の進み具合を保存
- **インタラクティブ**: コードエディタ付きで実際に試せる
- **称号システム**: 学習を進めて称号をゲット

## 📱 使い方

### 起動方法

1. ブラウザで `index.html` を開く
2. 「冒険を始める」ボタンをクリック
3. レッスンを選んで学習開始！

### 学習の流れ

1. **ホーム画面**: 学習状況の確認
2. **航路マップ**: レッスン一覧から学びたい内容を選択
3. **レッスン**: 解説を読んでコードを書いてみる
4. **完了**: レッスンをクリアしてポイント獲得
5. **航海日誌**: 進捗と称号を確認

## 💡 カスタマイズ方法

### レッスンの追加

`app.js`の`createLessons()`メソッド内に新しいレッスンオブジェクトを追加：

```javascript
{
    id: 6,
    icon: '🎯',
    title: '新しいレッスン',
    description: '説明文',
    content: `レッスンの内容（HTML可）`,
    sampleCode: `# サンプルコード`,
    points: 100
}
```

### スタイルの変更

`styles.css`の`:root`セクションでカラーパレットを変更できます：

```css
:root {
    --primary-color: #FF6B35;
    --secondary-color: #F7931E;
    /* その他のカラー変数... */
}
```
